# .zencoder Directory

**Purpose:** Internal agent documentation and build logs  
**Status:** Not for user consumption - Keep separate from main documentation

## What's Here

This directory contains:
- Internal agent build and test reports
- Historical development logs and summaries
- Agent-specific rules and guidelines
- Implementation phase documentation from development

## Why It's Separate

The `.zencoder/` directory serves a different purpose than `documentation/`:
- `.zencoder/` = Internal development history and agent instructions
- `documentation/` = User-facing guides, reports, and references

## Note

This directory should generally be ignored by users. If you're looking for:
- **Getting Started**: See `documentation/guides/quick-start.md`
- **Status Reports**: See `documentation/reports/`
- **Security Info**: See `documentation/security/`

For developers maintaining this project, the `.zencoder/rules/` directory may contain useful technical details about the original implementation.
